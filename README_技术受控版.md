# SINOSFT · 悬浮隧道浮桥（对外开源版）

## 技术受控，仅作理论仿真交流

本仓库用于**理论层面的交流与讨论**，展示的是「外观与逻辑」——
一座悬浮在水中的跨海通道看起来是什么样、它的宏观物理叙述建立在哪些通用关系上。

> **本仓库不是工程资料库。**
> 不含任何工程参数文件，不含具体吨位、壁厚、压强与工程尺寸，
> 不含工程实现细节、材料配比、内部公差体系、试验判据细节，
> 不含核心控制算法与任何内部资产。
> 文中结论一律限定在设定包络内，不作绝对化表述。

## 快速开始

```bash
cd sim
python verify_logic.py            # 退出码 0 = 通用物理关系自洽
python verify_logic.py --selftest # 鉴别力自测
```

仅依赖 Python 标准库。断言通过**只说明通用关系自洽**，不构成工程验证结论。

## 三分类公开纪律

- **A 宣传** —— 外观、理念、定性化的技术叙述；数值一律不落具体量。
- **B 验证** —— 只公开宏观物理逻辑的极简框架与自洽断言；
  工程实测数据与验证主线不在此列。
- **C 合作** —— 讨论、复现、提出改进；贡献即确权，详见 `CONTRIBUTING.md`。

**公开数据 ≠ 公开逻辑**：我们给出结论与可复算的通用关系，不给底牌。

## 如实说明的验证边界

载荷补偿与多级减震链已有逐项仿真与独立校验脚本背书。
**地震、海啸等极端复合工况仍在持续仿真优化**：
下沉与复浮的时序预算、泵站装机、完全浸没后的稳性都还缺一份专项设计；
疏散能力按已建成口径表述，更高目标要等实测放行才敢说。

我们如实呈现验证边界——海上的安全，靠的是可验证的严谨，不是漂亮的口号。
