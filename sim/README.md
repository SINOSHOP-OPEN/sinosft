# 宏观物理逻辑仿真框架（B 类 · 验证）

> **技术受控，仅作理论仿真交流。**

本目录只放**教科书级的通用物理关系**，用于说明《把桥"浮"在大海上》里
那些宏观叙述背后的逻辑形式。它不是 SINOSFT 的工程仿真程序。

## 三个文件

| 文件 | 内容 | 性质 |
|---|---|---|
| `force_balance.py` | 静力平衡 `ΣF = 0`、前馈补偿残差、单自由度传递率 | 通用物理 |
| `pascal_membrane.py` | 压强定义 `p = F/A`、帕斯卡等值传压、按面积分配合力 | 通用物理 |
| `verify_logic.py` | 上述关系的自洽性断言与鉴别力自测 | 独立校验 |

## 运行

```bash
python force_balance.py
python pascal_membrane.py
python verify_logic.py          # 退出码 0 = 全部自洽断言通过
python verify_logic.py --selftest  # 故意注入错误，验证断言有鉴别力
```

仅依赖 Python 标准库。
