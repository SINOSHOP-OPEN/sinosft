# 数据集决策仿真验证资料（公开层 V1.0）

> 本目录发布四个已完成数据知识产权登记申请的数据集的**档位化决策仿真验证资料**：
> 可复跑判定引擎、脱敏判定矩阵、验证报告与复现说明。
> 全部结论由脚本实跑产生；人只写边界，不写 PASS。

## 长期保密声明（请先读完再引用）

- 核心技术只可提**定性名称**，实现层永久内控：高度恒定潮汐发电、毫秒级动态载荷抵消、
  内外压平衡与压力缓冲。三者的实现参数、材料配比、控制律、标定值、可制造尺寸
  一律不进本目录、不进提交历史、不进任何公开页面。
- 公开范围仅限：语义档位枚举、布尔判定逻辑、规则锚点编号、脱敏判定矩阵、统计结论。
- 已按 Principle Zero 安检：全树扫描与提交信息扫描均零命中。

## 目录

| 路径 | 内容 |
|---|---|
| `sim/` | 四支档位化决策仿真引擎，仅用 Python 标准库 |
| `data/` | 脱敏判定矩阵（能源域为审核摘录，全量矩阵仍在登记包内） |
| `reports/` | 各域验证报告与复现说明 |
| `docs/` | 公开层技术白皮书与数据集编码规范 |
| `SHA256SUMS.txt` | 逐文件指纹，便于复核发布件未被篡改 |

## 复现

```bash
python sim/sft_vent_sim.py      # 通风导光消防：1944 例，负注入自测
python sim/sediment_sim.py      # 清淤与坝基：8192 例，负注入自测
python sim/evac_sim.py          # 疏散救生：6144 例，负注入自测
python sim/energy_sim.py        # 工程能源：18432 例，负注入自测
```

退出码 0 表示自检断言全部通过。四个引擎输入均为**语义档位枚举**，不含任何数值型
工程参数，也不读取外部数据文件。

## 判定口径与边界

1. 矩阵为**硬规则压力测试集**：任一档位违规即整案受限，故综合通过例很少属预期结果，
   用于证明规则拦截能力与判定可复现性，不代表工程方案不可行。
2. 本资料是**判定逻辑可复现性验证**，不是设计计算书，不替代计算流体力学分析、
   实体试验或现场实测，不作为结构安全与竣工验收依据。
3. 数据结论若需对外引用，只用档位与通过/受限口径，不得反推实现参数。
4. 各域登记申请号与凭证不在本公开包内；数字存证可另行核验。
