# 仿真验证方法与复现说明（SINO-Sediment r1）

## 方法
八项决策能力由 `sediment_sim.py` 计算。输入全部为语义档位：
- 淤积体档：薄层/中层/厚层（测量标注齐）或混级统计
- 回淤倾向：低回淤 / 高回淤
- 工艺配置档：交集与搭接达标 / 无交集 / 搭接不足 / 浓度低于基准
- 输送去向档：全链路闭合 / 水头不足 / 容量不足与分流超限 / 台账缺失
- 环保状态档：无超标 / 重金属超标 / 有机质超标 / TSS 重度超标
- 效果验收档：双达标实测 / 坝基未达标 / 下游减淤设计值 / 双未达标
- 浮体方案档：全项达标 / 储备不足 / 共振与误差超预算 / 冗余不足与检漏缺失

## 八模型
- dredging_window_ok：测量数据可用且达到清淤窗口（R8，决策一）
- tech_effective_ok：悬浮交集、搭接率、泥浆浓度共同决定工艺有效（R3/R5，决策二）
- route_compliant_ok：水头、容量、分流比、台账四项闭合（R4/R9/R10/R12，决策四）
- eco_compliant_ok：重金属/有机质污染刚性匹配处置去向（R1/R2，决策五）
- dual_effect_verified_ok：坝基加固与下游减淤独立验收，减淤量禁用水文设计值（R6/R11，决策三）
- float_carrier_ok：浮力储备、单舱冗余、共振与误差预算前置筛查（R13-R16/R18，决策六）
- height_error_controlled_ok：误差可归因且受控（R16/R17，决策七）
- service_life_match_ok：服役周期与回淤频次匹配（R17/R18，决策八）

## 复现
在本包根目录执行 `python sediment_sim.py`，自检输出：
枚举 8192 例、综合通过 5 例、受限 8187 例，
负注入冒烟断言 8/8 全部捕获。
逐条结果见 `data/样例数据_决策仿真判定矩阵.csv`，
统计与锚点分布见 `data/仿真验证报告.json`。

## 边界
档位化工程近似模型，用于判定逻辑可复现性验证；
不含可制造参数，不作为工程设计、结构安全或竣工验收依据。
