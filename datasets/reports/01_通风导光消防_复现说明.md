# 仿真验证方法与复现说明

## 方法
数据集五布尔判定标记由 sft_sim.py 计算，输入为语义档位枚举：
- 工况：正常通行 / 拥堵停车 / 局部火灾 / 进水极端
- 车流：正常 / 拥堵 / 停车；通风：活塞为主 / 机械兜底 / 排烟控制
- 分区：待机 / 主动分隔 / 硬隔离闭合；储水：储备充足 / 临界 / 超储备告警
- 浮力：完好 / 局部受损 / 进水受损；烟浓度：无烟 / 有烟

## 五模型
- ventilation_sustained：M1 风量持续性：活塞+机械兜底≥工况需风，火灾烟控不冲突
- zone_contained：M2 分区隔离：主动分隔不替代硬隔离，火灾/有烟须封闭门闭合
- fire_suppression_ready：M3 消防就绪：淡化达标+储备足+取水联动压载补偿+稳性达标
- buoyancy_redundant：M4 浮力冗余：固体浮力独立于压载，进水后残余比达标
- system_valid_under_congestion：M5 综合：四布尔按工况合成，拥堵额外要求机械兜底真启动

## 复现
执行 `python tools/sft_sim.py`，自检输出枚举 1944 例、
综合通过 312 例、受限 1632 例，并含负注入冒烟断言
（R-SFT-06 / R-SFT-09 违规配置必须被拦截）。

## 边界
档位化工程近似模型，用于判定逻辑可复现性验证，非设计计算书；
不替代 CFD、实体试验与现场实测。
